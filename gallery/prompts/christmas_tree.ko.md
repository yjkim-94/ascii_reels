## 스토리보드: Christmas Tree (15초, 파일 `christmas_tree.py`)

컨셉: 빛의 리본이 나선으로 감겨 오르며 트리를 그리고, 전구 480개가 연쇄로 켜지고, 큰 별이 충전돼 섬광과 충격파와 함께 점화되고, 트리 뒤로 불꽃놀이가 터지며 `MERRY CHRISTMAS`가 타이핑된다. 이펙트가 주인공, 화려하게.

## 정확한 값 (따로 말하지 않으면 모델 단위)

층은 세 개다: 글자 아래 그림 층(부드러운 이미지, 빛 번짐 없음), 글자 격자(빛 번짐 있음), 큰 글자 스프라이트 몇 개. 합성은 `그림 층 + 빛번짐(max(격자, 스프라이트))`.

배치: 트리, 줄기, 가랜드, 리본, 전구, 불티, 충전 불티, 불꽃을 `splat` 한 번(`cy = 0.47`, `scale = 1`)으로 그린다(z-buffer 하나라 트리가 뒤 불꽃을 가린다). 트리 끝 y = -0.59(화면 Y 0.18), 밑 y = 0.59(Y 0.76), 줄기 y 0.67까지, 땅 줄 화면 Y 0.80. `view(P) = rot_x(rot_y(P, 0.35 t), -0.15)`. 주광 `normalize(-0.4, -0.7, 0.6)`(기본값 대신).

트리: 높이 h = 0(끝) .. 1(밑), `y = -0.59 + 1.18 h`. 반지름은 4단(h 구간, 반지름 구간) 중 최댓값: (0-0.32, 0.02-0.17), (0.22-0.55, 0.08-0.26), (0.45-0.80, 0.12-0.35), (0.70-1.00, 0.18-0.42), `r0 + (r1 - r0) u^0.9`. 2~4단의 위 30%는 `0.35 + 0.65 clip(3.5 u, 0, 1)`로 그림자. 표면 점 9,000개: `h = uniform^0.8`, 각도 균등, 반지름 x `uniform(0.92, 1.04)`(잎 질감). 법선 `(cos a, -0.35, sin a)`. 조명: 주변 0.15, 주광 0.6, 테두리 0.3, 반사 0.1, x 그림자, x `0.8 + 0.4 lit`, `lit = smoothstep(ramp(t, 4.5, 7.5))`. 색은 에메랄드를 `0.15 lit + 0.6 grow`만큼 금 쪽으로. 줄기: 반지름 0.05 원기둥 위 500점, y 0.59~0.67, 밝기 0.45.

리본과 드러남: `qh = smoothstep(ramp(t, 0, 4.5))`. q(0..1)의 나선 점: 원뿔 위 `h = 1 - q`, 각도 `pi/2 + 10 pi q`, 반지름 x 1.06(밑동 앞쪽에서 출발). 트리 점은 `h > 1 - qh`인 곳만 그린다(qh > 0일 때만, 그래서 t = 0엔 아무것도 없음). 머리 바로 뒤 띠가 빛남: `grow = exp(-((h - (1 - qh))/0.03)^2)`(qh < 1일 때), 밝기에 x 0.8로 더함.
- 가랜드: q <= qh인 나선 900개 점, 화면 방향 글자, 밝기 `0.5 + 0.2 sin(6t - 30q)`, 금.
- 혜성 꼬리: 같은 점에 밝기 `clip(1 - (qh - q)/0.05, 0, 1)`, 금 x 1.6.
- 머리: splat 안의 흰 `@`(x 1.8), 34px 흰 `@` 스프라이트(x 1.6), 그림 층 금빛 후광 `0.5 exp(-d/0.05)`. 모두 처음 0.2초 동안 나타남.
- 불티: 260개, 각각 무작위 q에 묶여 머리가 그 q를 지날 때 태어난다(smoothstep 역함수). 위치는 그 순간 회전된 나선 점, 속도는 축마다 normal(0, 0.25), 낙하 `(0, 0.6, 0) age^2`, 수명 0.7초, 밝기 `1.1 (1 - age/0.7)`, 셋째마다 `*` 나머지 `+`, 금 x 1.4.
- 꼭대기 도착 번쩍임: `tip = exp(-((t - 4.5)/0.15)^2)`(별 윤곽에 씀).

전구: 3가닥 x 160, 가닥 s, 번호 i: `q = (i + 0.5)/160`, `h = 1 - 0.96 q`, 각도 `pi/2 + 8 pi q + 2.094 s`, 반지름 x 1.03. 켜지는 시각 `4.5 + 3.0 (1 - h)`(아래부터). 반짝임 `0.7 + 0.3 sin(5t + 위상)`, 막 켜진 전구는 0.25초 동안 `x (1 + 0.8 (1 - k))`로 더 밝고 `*`, 그 뒤엔 반짝임 > 0.9면 `*` 아니면 `+`. 색 번호: 7.5초 전엔 `n % 3`, 이후 `(n + int(4t) - int(6 (1 - h))) % 3`, 순서는 금·빨강·흰, 색 x 1.5.

장식 공: 원뿔 위 60개(h 0.12~0.95, 각도 균등, 반지름 x 1.05), 5.0~7.5초 균등 시각(정렬)에 0.35초 동안 튀어나옴. 화면 좌표계 z > 0.02(앞쪽 절반)일 때만 스프라이트로: 크기 `26 pop(k) + 4`px의 `O`, 색 x `(1 + 0.4 lit)`, 작은 흰 `'` 하이라이트(크기 `14 pop(k) + 4`)를 (-0.008, -0.006) 옆에. 튀어나오는 동안 둘레에 반지름 `0.015 + 0.05 k` 고리로 `.` 10개.

별(격자 칸, 화면 좌표): 중심 X 0, `Y = 0.47 + (-0.59 - 0.09) x 540/1098 ≈ 0.136`. 거리는 X 단위: `dx = X`, `dy = (Y - Y별) x 1098/540`. 오각별: `f = ((atan2(dy, dx) + pi/2 - 0.08 sin(0.7t)) / (2 pi/5)) mod 1`, 가장자리 반지름 `0.045 + (0.11 - 0.045) |1 - 2f|`.
- 4.5초부터: 윤곽 칸 `|d - 가장자리| < 0.012`에 `*`, 금 x `(0.45 + 0.8 tip)`.
- 충전 9.0~9.6초(`kc = ramp`), 점화 `ign = smoothstep(ramp(t, 9.6, 9.95))`: 몸통이 아래부터 차오른다. `d < 가장자리`이고 `dy > 0.11 - 0.22 smoothstep(max(kc, ign))`인 칸. 중심 `d < 0.5 가장자리`는 `@`, 흰 x 1.2 + 몸통색 x 0.3. 나머지는 `#`, `금 (0.9 + 0.7 ign)(1 + 0.25 sin 8t) + 흰 x flash`, `flash = exp(-((t - 9.6)/0.12)^2)`. 점화 후 윤곽은 흰 x 1.5.
- 충전 불티: 무작위 트리 점 220개(트리와 함께 회전)가 `(0, -0.68, 0.1)`로 날아감, 지연은 충전 진행의 0~0.3 균등, 진행의 0.7 동안 smoothstep, `*`, 금 x 1.5, 밝기 `0.9 (1 - k^4)`.
- 점화 후(전부 x ign): 빛줄기 16개, 각도 `2 pi m/16 + 0.3 (t - 9.6)`, 길이 0.24와 0.14를 번갈아 x 맥동, 1.05 R부터 10점. 십자 광채는 좌우 0.55, 위 0.30, 아래 0.22에 x `(0.85 + 0.15 sin 6t)`, 40점, 밝기 1.6 -> 0.1. 1.5 R 둘레를 각도 `+1.5t`로 도는 `*` 12개, 밝기 `0.8 + 0.6 clip(sin(9t + 3 각도), 0, 1)`. 색 `흰 x 0.5 + 금 x 0.9`. 빛줄기와 광채는 방향 글자.
- 그림 층: 후광 `(ign (0.35 + 0.1 sin 8t) + 0.6 flash) exp(-d/0.16)` 금, 화면 전체에 흰 `0.16 flash`.
- 충격파: 9.6초 뒤 0.9초 동안 `|d - 1.9 age| < 0.03`인 칸(별 중심에서 X 단위 거리)에 `o`/`.` 번갈아, 색 `(0.6 흰 + 0.6 금)(1 - age/0.9)`.

불꽃: 9.9, 10.3, 10.7, 11.0, 11.4, 11.8, 12.2초에 화면 (X, Y) = (-0.62, 0.20), (0.55, 0.16), (-0.25, 0.10), (0.70, 0.30), (-0.70, 0.34), (0.20, 0.08), (-0.05, 0.24). 깊이 z = -1.4에 둔다(화면 -> 모델은 `k = 3.2 / (3.2 + 1.4)`), 그래서 트리가 가린다.
- 로켓: 터지기 0.45초 전부터 흰 `|` 8점 꼬리가 Y 0.80에서 터질 곳까지 ease-out으로 올라감, 밝기 1 -> 0.2.
- 폭발: 입자 120개, 각도 균등, 속도 0.25~0.50 균등. 반지름 `속도 (1 - exp(-2.5 a)) / 2.5 x 2.2`, `X = X0 + r cos`, `Y = Y0 + (r sin + 0.09 a^2) x 540/1098`. 입자마다 나이 a, a - 0.05, a - 0.10을 가중치 1, 0.6, 0.35로 그린다. 머리는 4번째마다 `*` 나머지 `+`, 꼬리 두 점은 `(cos, sin + 0.3 a)` 방향 글자. 밝기 `가중치 1.6 exp(-age/1.0)(0.7 + 0.3 sin(20 age + 5 각도))`, 1.8초 동안. 폭발마다 두 색(입자 번갈아), 색 x 1.4.
- 하늘 물듦: 폭발마다 `0.10 exp(-age/0.35)` x 첫 번째 색을 땅 위 그림 층에 더한다.

배경
- 그림 층: 하늘 위 -> Y 0.80 지평선 색 세로 그라데이션, 그 아래 땅 (0.10, 0.13, 0.25) -> (0.05, 0.06, 0.12). 땅 위 따뜻한 빛 `0.12 lit exp(-hypot(X/0.6, 5 (Y - 0.80)))` 금.
- 별: 150개, X 균등, Y 0~0.62 균등, 반짝임 `0.3 + 0.7 clip(sin(2.4t + 위상), 0, 1)^3`, > 0.8 `*`, > 0.5 `+`, 아니면 `.`, 눈색 x 0.6 x 반짝임.
- 눈: 280송이(y = (y0 + v t) mod 1, v는 초당 0.025~0.08을 절반 속도로, 흔들림 0.005~0.02), 크기에 따라 `*`, `+`, `.`. 28%는 마지막에(트리 앞) 밝기 0.9로, 나머지는 먼저 0.55로.
- 땅 줄: Y 0.80~0.816 칸, `(열 + 행) % 4 == 0`이면 `~` 아니면 `_`, 눈색 x 0.35.

문구: `MERRY CHRISTMAS`, 굵은 고정폭 46px, 자간 +35%, Y 0.835 가운데, 금 x 1.1, 10.0~11.4초에 타이핑, 깜빡이는 커서. 반짝임: |Y - 0.835| < 0.03이고 |X| < 0.75 x 진행도인 칸 중 `sin(13t + 1.7 열 + 3.1 행) > 0.93`이면 금 `*`.

숫자: `lights` = 이미 켜진 전구 수, `ornaments` = 튀어나온 장식 수(앞뒤 모두 60), `fireworks` = 지금까지 터진 수, `letters` = 메인 splat이 그린 칸 수.

페이드: 하늘·별·눈·땅 줄을 뺀 모든 것(점 색, 스프라이트, 별, 문구, 그림 층의 빛)에 `1 - ease_out_cubic(ramp(t, 13.5, 15.0))`을 곱한다.

의도한 것이니 그대로 둔다: 첫 1초에는 리본이 밑동을 낮게 돌아서 빛나는 고리처럼 보이다가 올라간다. 불꽃은 트리 둘레에만 보인다(뒤는 가려짐). 점화 섬광이 잠깐 화면을 하얗게 덮는다.
