## 화면 구성
- 위쪽 1098px: 렌더 화면. 108 x 61칸 글자 그리드, 칸 하나는 10 x 18px. 배경은 검정.
- 렌더 화면 왼쪽 아래: 고정폭 글꼴 상태 글자 3줄. 1줄은 계정(내가 안 주면 `@your.handle`), 2~3줄은 줄거리를 따라 올라가는 숫자 2~4개와 `letters N`(이번 프레임에 그린 칸 수).
- 렌더 화면 오른쪽 위: 분홍 점과 경과 시간, 예: `● t 3.27s`.
- 그 아래: 이 스크립트 자신을 보여주는 코드 패널. 머리줄 왼쪽에 파일 이름, 오른쪽에 초록 점 `running · 30 fps`. 어두운 테마로 색칠한 코드와 줄 번호, 초당 6줄 이하로 부드럽게 스크롤, 강조된 줄 하나 끝에 깜빡이는 분홍 블록 커서(지금 타이핑 중인 것처럼).
- 코드 주석은 영어로 쓴다(화면에 나오고, 코드 글꼴에 한글이 없을 수 있다).

## 렌더링 방식
- 글자 아틀라스: 쓰는 글자(공백, `.,:;*+'|-/\_~=#@%&o0O`, A-Z, a-z, 0-9, `$!?<>{}[]()^`)를 굵은 고정폭 글꼴(예: DejaVu Sans Mono Bold 15)로 10 x 18 비트맵에 한 번씩 그려 둔다.
- 밝기 계단: 글자를 잉크 면적 순으로 정렬해 고르게 28개 정도 고른다. 칸의 밝기(0~1)가 계단에서 글자를 고른다.
- 칸마다 글자 번호 하나와 RGB 색 하나(강조는 1을 넘어도 됨). 합성은 글자 비트맵 x 색, 그다음 빛 번짐(4배 축소, 가우시안 블러, 확대, 0.9배 정도 더하기).
- 더 밝은 것이 이긴다: 칸은 더 밝은 글자로만 덮어쓴다. 사라지는 물체가 검은 구멍을 남기지 않고 배경이 드러난다.
- 3D 물체는 점 구름: 표면 점 수천 개(법선 포함)를 회전, 원근 투영해 칸마다 가장 앞 점만 남기고(z-buffer), 주광, 도는 테두리광, 가끔 번쩍이는 반사광으로 음영을 준다.
- 가는 선(빛줄기, 촉수, 줄기)은 화면에서 뻗는 방향에 맞는 `| / \ -` 글자로 그린다.
- 배경 층: 흐리게 반짝이는 별이나 옅은 글자비를 깔아 화면이 죽어 있지 않게 한다.

## 연출 규칙
- 첫 1초 안에 무언가 움직인다(훅). 형체 완성은 길이의 55~70% 지점. 클라이맥스는 하나, 앞의 어떤 장면보다 확실히 강하게. 마지막 1.5초는 첫 화면으로 페이드해서 반복 재생이 이어지게.
- 장면 시간은 전부 `T_*` 상수로 스크립트 맨 위에 모은다. 코드 패널에서 이 부분이 타임라인으로 읽힌다.
- 주석은 영어, 한 줄 72자 이하(화면에 나온다).

## 기준 수치 (픽셀까지 같을 필요는 없고 비슷한 느낌이 목표)
- 좌표: 화면 `X`는 폭 전체 -1..1(가운데 0), `Y`는 0(위)..1(렌더 화면 아래). 3D 모델 단위: 1 = 화면 폭 절반, y는 아래쪽, z는 보는 사람 쪽.
- 투영: `k = f / (f - z)`, `f = 3.2`. 화면 `X = x*k*scale`, `Y = cy + y*k*scale*540/1098`(x와 y가 같은 단위가 되게).
- 점 색 = `rgb * (0.35 + 0.9 * 밝기)`. 조명: 주광은 위 앞쪽 `(0, -0.8, 0.6)`, 테두리광은 초당 0.9rad로 돌며 `(1 - |n.z|)^1.5`로 가중, 반사광 지수 12.
- 빛 번짐: 1/4로 축소, 가우시안 블러 반지름 3, 쌍선형 확대, 0.9~1.1배 더하기.
- 상태 글자: 일반 고정폭 30px, 색 #e8eaee, 줄 간격 40px, 왼쪽에서 22px, 마지막 줄은 코드 패널 22px 위. 경과 시간: 같은 글꼴, 분홍 #ff6b9e, 오른쪽 위 약 37px 높이.
- 코드 패널: 머리줄 62px #1e2026, 파일 이름 26px. 코드: 일반 고정폭 24px, 줄 높이 36px, 줄 번호 20px #4e5460(64px 여백), 배경 #16181d. 색: 키워드 #c678dd, 함수 #61afef, 문자열 #98c379, 숫자 #d19a66, 주석 #6a737d, 대문자 상수 #56b6c2, 나머지 #dcdfe4. 강조 줄은 패널 위에서 6번째 줄, 배경을 +0.06 정도 밝게, 커서는 폭 13px 분홍 블록이 초당 2.5번 깜빡.
- 큰 글씨 자막(스토리보드에 문구가 있을 때만): 굵은 고정폭 46px, 자간 +35%, 가운데 정렬.
- 인코딩: `ffmpeg -f rawvideo -pix_fmt rgb24 -s 1080x1920 -r 30 -i - -c:v libx264 -preset medium -crf 17 -pix_fmt yuv420p -movflags +faststart`.

## 진행 방법
1. 먼저 아래 스토리보드를 표(장면, 시간, 움직임, 색, 클라이맥스)로 보여 주고 내 확인이나 수정을 기다린다.
2. 스크립트를 쓴다. 장면마다 가운데 시점의 정지 화면을 뽑아 직접 보고 확인한다: 잘린 곳 없는지, 상태 글자와 겹치지 않는지, 클라이맥스가 가장 밝은 순간인지, 반복 이음새가 깔끔한지. 고치고 반복.
3. 전체 mp4를 렌더하고 파일 경로와 걸린 시간을 알려 준다.
