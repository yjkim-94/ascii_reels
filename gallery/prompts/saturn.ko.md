## 스토리보드: Saturn (15초, 파일 `saturn.py`)

컨셉: 흩어진 먼지가 나선으로 모여 행성이 되고, 적도에서 입자가 퍼져 고리가 된다. 화면 문구 없음.

장면
| # | 시간(초) | 내용 | 다이나믹 포인트 | 숫자 |
|---|---|---|---|---|
| 1 | 0.0-1.0 | 별, 먼지가 나타나며 안쪽으로 돌기 시작 | 훅 | dust 0부터 증가 |
| 2 | 1.0-4.5 | 먼지가 나선으로 모여 구체가 됨 | 알갱이가 닿을 때(약 4.55초) 짧게 번쩍 | dust -> 4,812 |
| 3 | 4.5-6.0 | 행성 자전, 띠 무늬가 나타남 | | |
| 4 | 6.0-9.5 | 적도에서 입자가 궤도로 퍼짐(안쪽 고리부터), 전체가 0 -> 26.73도 기울어짐 | 카시니 간극이 열림 | ring -> 12,000, tilt -> 26.73 |
| 5 | 9.5-12.0 | 태양이 행성 뒤에서 왼쪽 위로 떠오르고 주광이 앞에서 뒤로 돈다 | **클라이맥스**: 고리 금빛, 행성 가장자리가 빛남, 빛줄기 | |
| 6 | 12.0-13.5 | 역광 속 행성이 계속 돈다 | | |
| 7 | 13.5-15.0 | 전부 페이드, 별만 남음 | 반복 이음새 | |

상태 글자: `@your.handle` / `dust 4,812   ring 12,000   tilt 26.73°` / `letters N`.

팔레트
- 별 (0.60, 0.65, 0.80). 흩어진 먼지: 크림.
- 행성: 크림 (1.00, 0.88, 0.65), 호박 (0.95, 0.62, 0.28), 짙은 띠 (0.70, 0.45, 0.25).
- 고리: 베이지 (0.90, 0.82, 0.65).
- 클라이맥스: 금 (1.00, 0.85, 0.45), 흰색 (1, 1, 1).

## 정확한 값 (따로 말하지 않으면 모델 단위, R = 행성 반지름)

아래는 모두 모델 단위다. 행성, 먼지, 고리, 태양을 `splat` 한 번(`cy = 0.42`, `scale = 1.15`)으로 그린다. 즉 모델 1 = 화면 폭 절반 x 1.15.

좌표 변환
- `view(P) = roll(rot_x(P, -radians(tilt)), -0.22)`. `rot_x`는 y 아래, z 보는 사람 쪽 기준 보통의 x축 회전, `roll`은 화면 평면(x, y) 회전. 행성, 먼지, 고리는 `view`를 거친다. 태양과 빛줄기는 거치지 않고 화면 좌표계 값 그대로 쓴다.
- `tilt = 26.73 * smoothstep(ramp(t, 6.0, 9.5))`도.

별: 180개, 화면 X -1..1, Y 0..0.86 균등. 반짝임 `tw = 0.35 + 0.65 * clip(sin(2.2 t + 위상), 0, 1)^3`. tw > 0.8이면 `*`, > 0.5이면 `+`, 아니면 `.`. 색은 별색 x tw x 0.8.

행성 = 내려앉은 먼지 그 자체(점을 따로 추가하지 않음)
- 표면: 피보나치 구 위 4,812점 `u`(`i = 0..n-1`, `y = 1 - 2 (i + 0.5)/n`, `r = sqrt(1 - y^2)`, 각도 `i * pi * (3 - sqrt 5)`, 점 `(r cos, y, r sin)`). 알갱이 i는 점 i에 내려앉는다. 이 점들을 (R, 0.9 R, R)로 늘린다, R = 0.28. 법선은 `u * (1, 1/0.9, 1)`. 자전 `rot_y(.., 0.35 t)`.
- 위도 `lat = u.y`의 띠: `b = sin(19 lat) + 0.45 sin(47 lat + 1.3)`. b > 0.6 크림, b > -0.4 호박, 나머지 짙은 띠. 처음엔 크림 단색이고 `smoothstep(ramp(t, 4.5, 6.0))`로 띠가 섞여 나온다.
- 폭풍: 띠 색을 `exp(-((lat - 0.35)/0.07)^2 - ((lon - 1.0)/0.25)^2)`만큼 35% 어둡게, lon = atan2(u.z, u.x).

먼지
- 시작: 반지름 0.40~0.88 균등, 각도 a0 0..2pi 균등(나선 팔 없음), 높이 normal(0, 0.03). 원반을 `rot_x(-0.95)`(옆에서 약 54도)로 돌려 소용돌이가 비스듬히 보이게. 시작할 때 가장 바깥 알갱이가 잠깐 화면 가장자리를 넘고 상태 글자 밑으로도 지나가는데, 의도한 것이니 그대로 둔다.
- 알갱이마다 지연 0~1.4초 균등, 진행도 `k = smoothstep(clip((t - 지연) / 3.1, 0, 1))`. 원반 각도 `a0 + 0.9 t + 3.0 (1 - k)`. 위치 = `시작점 * (1 - k) + 자전하는_표면점 * k`(3D 직선 보간).
- 흩어진 먼지 밝기: 0.15~0.5 균등 x 나타나기 `smoothstep(ramp(t, 0, 0.6))`(t = 0에서 0이라 아무것도 그려지지 않는다). 날아가는 중인 알갱이는 착지할 점의 법선을 쓴다.

조명(행성)
- `sun = (-0.10 - 0.30 ks, -0.05 - 0.22 ks, -1.2)`, `ks = smoothstep(ramp(t, 9.5, 12.0))`. 주광 `L = normalize(front * (1 - ks) + normalize(sun) * ks)`, `front = normalize(-0.5, -0.6, 0.65)`. 기본 주광 대신 이것을 쓴다.
- `diff = max(0, n.L)`, `edge = (1 - |n.z|)^1.5`, 테두리광 `r = normalize(cos 0.9t, -0.4, sin 0.9t)`, `rim = max(0, n.r) * edge`, `spec = max(0, n.normalize(L + (0,0,1)))^12`.
- `lum = 0.10 + 0.75 diff + (0.35 + 0.9 ks) rim + 0.15 spec`. 행성에는 반짝임(glint) 없음.
- 그다음 `lum = lum * k + 먼지밝기 * (1 - k)`, 가장자리 빛 `0.8 ks (1 - |n.z|)^2 k`(가장자리 전체를 고르게 밝혀 어두운 원판 둘레에 얇은 후광이 된다. 한쪽 초승달로 바꾸지 않는다), 착지 번쩍임 `0.9 exp(-((t - 4.55)/0.18)^2) k`를 더하고 0..1로 자른다. 번쩍임은 짧고, 클라이맥스는 더 오래 고리까지 넓게 빛나서 더 강하게 보인다.
- 행성 색: 띠 색을 `ks`만큼 금색 쪽으로 60% 섞는다.

고리: 적도면 입자 12,000개
- C 고리 2,500개 1.25~1.50 R(깊이 0.55), B 고리 6,000개 1.50~1.86 R(깊이 1.0), 카시니 간극 1.86~1.93 R(비움), A 고리 3,500개 1.93~2.29 R(깊이 0.75). 깊이에 `0.8 + 0.2 sin(180 r)`을 곱해 잔고리 무늬. 각 고리 안에서 반지름과 각도 균등.
- 퍼짐: 출발 전 입자는 그리지 않는다. 입자는 `6.0 + (r - 0.35) * 6`초(r은 모델 단위)에 출발해 1.2초 동안 smoothstep으로 1.03 R에서 r까지 나간다. 궤도 각도 `a0 + 0.55 (r/0.35)^-1.5 t`.
- 밝기: `깊이 * (0.25 + 0.55 |up . L|) + 0.9 * ks * max(0, -L.z) * 깊이`, `up`은 고리면 법선 `view((0, -1, 0))`. 그림자: 화면 좌표계에서 `p . L < 0`이고 p와 행성 중심을 지나는 L 방향 직선 사이 거리가 R보다 작으면(단순 구 판정) x0.35(경계는 딱 끊김). 고리 밝기는 1을 넘을 수 있으니 그리기 전에 1로 자른다.
- 색: 베이지를 `ks`만큼 `0.6 금 + 0.4 흰`으로 섞는다.

태양(화면 좌표계, 같은 z-buffer라 행성에 가려진다)
- 중심: `sun` 위치에 `@` 하나, 밝기 `ks`, 색 금 x 1.6. ks = 0이면 태양은 아무것도 그리지 않는다. 빛줄기 12개, 각도 a = 0, 30, ... 330도. 길이 `0.06 + 0.22 ks (1 + 0.5 cos 3a)`, 0.02부터 길이까지 고른 간격으로 14개 점(모델 단위), 방향에 맞는 글자(`| / \ -`), 밝기 `(1 - 0.8 s/길이) * ks`, 색 금 x 1.6. 빛줄기는 회전하지 않는다.

숫자
- `dust = int(4812 * mean(k))`(첫 프레임부터 부드럽게 증가).
- `ring = int(12000 * mean(퍼짐 진행도))`, `tilt`는 위 값 소수 둘째 자리, `letters`는 행성·고리·태양 splat이 그린 칸 수(z-buffer 뒤 밝기 0.02 초과인 점).

페이드: 별을 뺀 모든 것의 색에 `1 - ease_out_cubic(ramp(t, 13.5, 15.0))`을 곱한다.

길이를 줄이면 위에서 시간인 것(장면 시간, 지연, 착지 3.1초, 퍼짐 1.2초, `(r - 0.35) * 6` 출발 간격, 번쩍임 중심과 폭, 0.6초 나타나기)에는 배율을 곱하고, 속도(소용돌이 0.9, 자전 0.35, 공전 0.55, 테두리광 0.9)는 같은 배율로 나눈다. `3.0 (1 - k)` 비틀림은 속도가 아니라 각도라서 그대로 둔다.
