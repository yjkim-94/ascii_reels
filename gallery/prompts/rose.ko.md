## 스토리보드: Rose (15초, 파일 `rose.py`)

컨셉: 빛 입자가 땅의 한 점으로 빨려 들어가고, 줄기가 솟아 잎 두 장을 펴고, 봉오리가 맺혀 큰 진홍 장미가 한 장씩 피어난 뒤 금빛 빛과 꽃가루가 터진다. 화면 문구 없음.

## 정확한 값 (따로 말하지 않으면 모델 단위)

식물 전체(줄기, 가시, 잎, 꽃받침, 꽃잎, 꽃잎 윤곽선, 꽃가루)를 `splat` 한 번(`cy = 0.44`, `scale = 1.0`)으로 그린다. 모델 y = 0이 줄기 끝, 화면 Y 0.44. 빛줄기는 그다음 두 번째 splat으로 그린다(더 밝은 것이 이김). 모든 조명의 주광은 `L = normalize(-0.45, -0.75, 0.55)`(기본값 대신). 아래 조명은 기본 식에 주어진 가중치(주변광 + 주광 x diff + 테두리광 x rim항 + 반사광 x spec항)를 쓰고 반짝임은 없다.

배경(페이드하지 않음, 반복 화면)
- 빛 입자: 170개, 화면 X -1..1, Y 0..0.83 균등. 초당 `k * 0.83 / 15`씩 떠오름(k는 1 또는 2 무작위, 그래서 정확히 반복), 0..0.83 안에서 돈다. 반짝임 `tw = 0.25 + 0.75 * clip(sin(4 t + 위상), 0, 1)^2`, tw > 0.8이면 `+` 아니면 `.`, 색은 빛 입자색 x tw.
- 흙: 화면 Y 0.83..0.848인 격자 칸, `(열 * 7 + 행) % 3 == 0`이면 `.` 아니면 `_`, 색은 흙 x 0.6.

훅(화면 좌표, 격자 칸, 식물보다 먼저)
- 수렴 입자: 420개, 반지름 r0 0.25~0.8 균등, 각도 a0 균등, 지연 0~0.35초 균등. 진행도 `k = clip((t - 지연) / 0.85, 0, 1)`. t < 1.2이고 k < 1일 때만 그린다. 반지름 `r0 (1 - smoothstep(k))`, 각도 `a0 + 3.5 k`, 화면 `X = r cos a`, `Y = 0.81 - 0.55 r |sin a|`. 밝기 `(0.5 + 0.8 k) * clip(t / 0.15, 0, 1)`, k > 0.7이면 `*`, > 0.35이면 `+`, 아니면 `.`, 색은 수렴 입자색 x 밝기.
- 흙 튐: `d = ramp(t, 0.6, 1.9)`가 0 < d < 1일 때, `tt = 1.35 d`, 사라짐 `fl = 0.9 (1 - d)`. 알갱이 70개: X = `dirx * 속도 * tt`(dirx ~ normal(0, 0.6), 속도 0.15~0.4 균등), Y = `0.83 - up * 속도 * tt * 0.5 + 0.25 tt^2`(up 0.4~1.0 균등), `.` 또는 `,`, 색 흙 x 1.8 x fl. X -0.1~0.1, Y 0.835에 `~` 21개, 색 흙 x 2.2 x fl. 후광: `hypot(X/0.12, (Y-0.83)/0.05) < 1`이고 Y < 0.85인 칸에 `.`, 색 (1.0, 0.6, 0.35) x 0.8 fl.

줄기
- 축(s = 0 흙 .. 1 끝): `x = 0.045 sin(1.5 pi s) + 0.010 sin(1.2 t + 2 s) s`, `y = 0.79 (1 - s)`, `z = 0.030 cos(1.2 pi s)`.
- 반지름 0.022 관: s 방향 150 x 둘레 10. `s <= grow`이고 grow > 0인 곳만 보인다, `grow = ease_out_cubic(ramp(t, 0.6, 4.0))`.
- 조명: 주변 0.15, 주광 0.6, 테두리 0.3, 반사 0.1. 자라는 끝: grow < 1인 동안 `0.7 exp(-((s - grow)/0.03)^2)`를 밝기에 더하고 같은 양 x 0.5만큼 색을 밝힌다.
- 가시: s = 0.20, 0.30, 0.45, 0.60, 0.70, 0.82에 오른쪽/왼쪽 번갈아 x로 0.034 떨어진 점 하나. 오른쪽 `>`, 왼쪽 `<`, 줄기가 지나가면 밝기 0.55.

잎(2장): s = 0.36에서 (-1, 0, 0.35) 방향, s = 0.55에서 (1, 0, 0.25) 방향(정규화). `kl = smoothstep(ramp(t, 2.4, 4.0))`. 격자 u 0..1(22) x v -1..1(9). 길이 `0.17 (0.3 + 0.7 kl)`, 중심선 `기점 + 길이 (u 방향 + 0.25 u^2 (0, 1, 0))`(아래로 처짐), 폭 `0.055 sin(pi u)^0.8 (1 + 0.08 sin(30 u))`. 잎맥을 따라 반으로 접혀 있다가 `fold = 1.3 - 1.05 kl`로 펼쳐진다: 점 = 중심선 + `perp * v w cos(fold) + (0, -1, 0) |v| w sin(fold)`, `perp = normalize(방향 x (0, -1, 0))`. 양면 법선(카메라 쪽으로 뒤집기). 조명: 주변 0.15, 주광 0.65, 테두리 0.3, 반사 0.15, 잎맥 `|v| < 0.15`는 0.25 더함.

꽃 좌표계: 꽃잎은 꽃 축 (0, -1, 0) 둘레에 만들고 `head_view(P) = rot_x(rot_y(P, 0.25 t), -0.85) + stem_axis(1, t)`(자기 축으로 회전, 0.85rad 앞으로 숙여 안을 들여다보게). 법선도 같은 회전만 거치고(이동 없음) 카메라 쪽으로 뒤집는다(양면).

꽃잎: 5겹 k = 0(안) .. 4(바깥), 3, 5, 7, 9, 10장 = 34장
- 겹별: 길이 0.20, 0.28, 0.36, 0.44, 0.50 / 기점 반지름 r0 0.014, 0.036, 0.058, 0.080, 0.098 / 폭 계수 0.78, 0.72, 0.68, 0.64, 0.62(바깥이 좁아 꽃잎 사이 틈이 보임) / 봉오리 각도 0.08, 0.14, 0.20, 0.26, 0.32rad / 펼친 각도 0.20, 0.42, 0.65, 0.88, 1.05 / 끝 말림 0.15, 0.30, 0.45, 0.60, 0.75.
- k겹 i번째 꽃잎 각도 `phi = 2 pi i / n_k + 2.4 k`. 꽃잎마다 작은 무작위: 길이 x (1 + normal(0, 0.07)), 펼친 각도 + normal(0, 0.06), 말림 + normal(0, 0.10). 펼쳐지는 시각 `6.5 + (4 - k) 0.6 + 0.05 i + uniform(0, 0.08)`초부터 1.1초 동안 smoothstep(`po`).
- 꽃 크기 `size = 0.75 kb + 0.25 mean(po)`, `kb = smoothstep(ramp(t, 4.0, 5.5))`. 4.0초 전에는 꽃을 그리지 않는다. 길이와 r0에 size를 곱한다.
- 꽃잎 면, u = 0.02..1(18), v = -1..1(13): `rad = (cos phi, 0, sin phi)`, `tan = (-sin phi, 0, cos phi)`. 중심선 각도 `th(u) = theta + curl u^2`, `theta = 봉오리 + (펼침 - 봉오리) po`, `curl = 말림_k po`. 중심선 = `r0 rad + cumsum(sin th rad + cos th (0, -1, 0)) / 18 * 길이`. 반폭 `w = 폭계수 * 길이 * u^0.55 (1 - 0.3 u^5)`. 점 = 중심선 + `tan v w` - `rad (cup v^2 w)`(`cup = 0.5 - 0.25 po`) + `rad (0.5 po ((max(|v| - 0.55, 0)/0.45)^2) w u)`(펼친 꽃잎 가장자리가 바깥으로 말림).
- 법선: 격자에서 `cross(d/du, d/dv)`.
- 색: `진홍 + (다홍 - 진홍)(1 - k/4) 0.8`에 `0.55 + 0.45 min(u/0.25, 1)`을 곱한다(밑동이 어둡게).
- 밝기: 조명(주변 0.12, 주광 0.6, 테두리 0.35, 반사 0.2) x `(0.5 + 0.5 u)` x 잎맥 `0.85 + 0.15 cos(9 v) * (u > 0.15이면 1 아니면 0)`. 가장자리 계수 `E = max(|v|^4, u^6)`. 펼쳐지는 동안 `0.6 * 0.5 sin(pi po) E`를 더한다.
- 클라이맥스 `kc = smoothstep(ramp(t, 10.0, 10.6)) (1 - 0.5 smoothstep(ramp(t, 10.8, 12.0)))`: `0.3 kc E`와 금빛 중심 `core = 0.45 kc (1 - k/4)(1 - u)`를 더한다. 색은 `E (0.2 po + 0.3 kc)`만큼 분홍 쪽, `core`만큼 금 쪽으로 섞는다.
- 꽃잎 윤곽선(꽃잎이 한 장씩 보이게 하는 핵심, 빼지 않는다): 꽃잎마다 같은 면 식으로 양쪽 긴 가장자리(u = 0.05..1, 36개, v = -1과 1)와 끝(u = 1, v = -1..1, 20개)을 뽑는다. 글자는 윤곽선의 화면 방향 글자(`| / \ -`). head_view 다음에 윤곽 점을 카메라 쪽으로 0.004 당겨, 앞 꽃잎의 가장자리가 자기 면보다 앞서게 한다. 밝기 `(0.85 + 0.15 sin(pi po)) (1 + 0.4 kc)`, 색은 윤곽색 (1.00, 0.45, 0.55)을 `0.5 kc`만큼 분홍 쪽으로.

꽃받침: 각도 `2 pi j / 5 + 0.3`의 초록 잎 5장, 같은 면 식에 폭 계수 0.35, 길이 `0.20 size + 0.02`, r0 `0.05 size`, cup 0.3, 각도 `0.12 + 2.2 ks`, 말림 `0.3 ks`, `ks = smoothstep(ramp(t, 5.5, 6.5))`. 조명: 주변 0.15, 주광 0.6, 테두리 0.3, 반사 0.1.

꽃가루: 320알, 각각 `10.0 + uniform(0, 1.2)`초에 출발해 3.5초 동안, 중심 `head_view((0, -0.06, 0))`에서. 방향: 3D normal(0, 1)의 y를 `-0.6 |y| - 0.1`로 바꾼 뒤 정규화, 속도 0.15~0.45 균등. 위치 `중심 + 방향 속도 age^0.6 + (0, -0.04, 0) age`. 밝기 `1.2 exp(-age / 1.6)`, 5번째마다 `*`, 나머지는 `.`와 `+` 번갈아, 색 금 x 1.3.

빛줄기(두 번째 splat, 중심 둘레 화면 평면, 모델 단위): `kr = smoothstep(ramp(t, 10.0, 10.5)) (1 - 0.6 smoothstep(ramp(t, 10.6, 12.0)))`. 16개, 각도 `2 pi m / 16`, 길이 `0.12 + 0.48 kr (1 + 0.35 cos 4a)`, 0.06부터 길이까지 16점, 위치 `중심 + (cos a s, sin a s, 0.3)`, 밝기 `(1 - 0.85 s/길이) kr`, 방향 글자, 색 금 x 2.4.

숫자: `petals = round(sum(po))`, `layers`는 꽃잎이 모두 다 펼쳐진(po > 0.99) 겹 수, `bloom = mean(po) * 100` 소수 없이, `letters`는 식물 splat이 그린 칸 수.

페이드: 식물, 꽃가루, 빛줄기의 색에 `1 - ease_out_cubic(ramp(t, 13.5, 15.0))`을 곱한다. 빛 입자와 흙은 페이드하지 않는다.

의도한 것이니 그대로 둔다: 만개하면 바깥 꽃잎이 줄기 윗부분 위로 늘어진다. 뒤쪽 꽃잎은 촘촘히 겹쳐 무늬처럼 보이고 앞쪽 꽃잎은 윤곽이 또렷하다.
