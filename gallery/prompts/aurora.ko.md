## 스토리보드: Aurora (18초, 파일 `aurora.py`)

컨셉: 칠흑 같은 밤. 별똥별이 첫 별들을 켜고, 침엽수 숲과 호수가 드러나고, 오로라 커튼이 하나씩 자란다. 하늘이 잠깐 숨을 고른 뒤 빛의 파도가 커튼을 따라 달려가며 서브스톰이 터진다: 커튼이 S자로 접히고, 광선이 하늘 꼭대기까지 솟고, 아래 가장자리가 분홍으로 타오르며, 호수가 그 모습을 비춘다. 화면 문구 없음.

## 정확한 값 (화면 단위: X -1..1, Y 0 위 .. 1 렌더 화면 아래)

층은 둘이다: 그림 층(글자 아래 부드러운 이미지, 270 x 274로 계산해 확대, 빛 번짐 없음)과 글자 격자(빛 번짐 있음). 지평선·숲 기준선 Y 0.60, 호수는 Y 0.612를 기준으로 뒤집혀 비치고 Y 0.86에서 끝난다.

페이드: `f_aur = 1 - ease(ramp(t, 16.5, 17.3))`, `f_land = 1 - ease(ramp(t, 17.0, 17.6))`, `f_star = 1 - ease(ramp(t, 17.3, 18.0))`, `reveal = smoothstep(ramp(t, 1.0, 4.0))`.

오로라 함수 `aurora(X, Y, t)` -> 세기 A와 색 C(두 층 모두에 씀):
- 띠 b = 0..4, 태어나는 시각 4, 7, 8, 9, 10초, `a = smoothstep(ramp(t, 탄생, 탄생 + 1.5))`. 기준 높이 0.50, 0.42, 0.35, 0.28, 0.21(띠 0은 0.08 낮게 시작해 4~7초에 떠오름), 진폭 0.030, 0.040, 0.045, 0.050, 0.040, 주파수 2.2, 1.7, 2.6, 1.9, 2.4, 위상은 띠마다 무작위, 커튼 높이 H 0.10, 0.13, 0.15, 0.16, 0.14.
- 폭풍 세기 `G(t) = smoothstep(clip((t - 12.5)/0.7, 0, 1)) (1 - smoothstep(clip((t - 15)/1.5, 0, 1)))`와 그 누적 적분 `GI(t)`(수치 적분). `phase = 0.7 t + 2.2 GI`, `drift = 0.03 t + 0.12 GI`(폭풍 때 움직임이 끊김 없이 빨라짐).
- 정적: 전체에 `1 - 0.3 smoothstep(ramp(t, 11, 11.5)) (1 - smoothstep(ramp(t, 12, 12.8)))`.
- 빛의 파도: 앞머리 `xw = -1.3 + 2.8 ramp(t, 12.0, 12.8)`, `pulse = exp(-((X - xw)/0.12)^2)`(파도가 달리는 동안만), `awake = smoothstep(clip((xw - X)/0.4, 0, 1))`(t >= 12, 15~16.5초에 사라짐), 깨어난 곳의 폭풍 `S = awake * smoothstep(ramp(t, 12.3, 13.3))`.
- 아래 가장자리 `y0 = 기준 + 진폭 sin(주파수 X + phase + 위상) + 0.012 sin(5.3 X - 1.6 phase + b) + S 0.045 sin(4.2 X + 2.4 phase + 1.7 b)`(마지막 항이 서브스톰 S자 접힘). `hgt = y0 - Y`.
- 광선: X 방향 1D 노이즈, `u = (0.35 X + drift (1 + b % 2) + 0.2 b) mod 1`, 값 r(0..1), `ray = 0.35 + 0.65 clip((r - 0.25)/0.6, 0, 1)^1.5`.
- 커튼: 가장자리 위는 `exp(-hgt / (H (1 + 1.8 S)))`, 아래는 `exp(hgt / 0.006)`(날카로운 단). 양옆으로 `clip(1.15 - 0.5 |X|, 0, 1)`만큼 약해짐.
- `I = a * 커튼 * ray * 옆 * (0.55 + 0.1 b) * 정적 * (1 + 0.7 S + 1.2 pulse)`.
- 색: `edge = exp(-max(hgt, 0)/0.035)`, `top = (1 - edge)(0.35 + 0.65 smoothstep(ramp(t, 7, 11)))`, `색 = 가장자리초록 edge + 몸통초록 (1 - edge)(1 - top) + 보라 top`, 그다음 `0.85 S edge`만큼 분홍 쪽, `0.6 pulse`만큼 흰빛 쪽으로. A = I의 합, C = 색 x I의 합.

그림 층
- 하늘: 하늘 위 -> 지평선 하늘(Y 0.60) 세로 그라데이션, 그 아래는 물 (0.05, 0.10, 0.18) -> Y 1에서 (0.01, 0.02, 0.04). 전체 x reveal x f_land. 은하수: 부드러운 노이즈, `band = exp(-((0.5 X + Y - 0.32)/0.12)^2)`, `clip(노이즈 - 0.5, 0, 1) band 0.12 reveal f_star` x 별색을 더함.
- 오로라 빛: 지평선 위에 `0.55 f_aur C`를 더함.
- 별똥별 빛: 1.4초까지 머리 둘레에 `0.7 exp(-d/0.07)`.
- 숲: 소나무 삼각형 70개, 중심 X -1.05~1.05 균등, 높이 0.025~0.085, 반폭 = 높이 x uniform(0.35, 0.5), Y 0.60 위에 섬. 색은 나무색 x `(0.5 + 0.5 reveal)`.
- 호수(Y > 0.612): 하늘 그림을 0.612 기준으로 뒤집고, 화소마다 `(잔물결노이즈 - 0.5) x 60 (Y - 0.612)`화소만큼 옆으로 밀어(아래로 갈수록 크게 일렁임) 물 그라데이션 위에 x 0.45로 더함.

글자 격자
- 별: 400개. 처음 60개는 별똥별 길 (-0.95, 0.20) -> (0.85, 0.48)을 따라(X normal(0, 0.06), Y normal(0, 0.03)) 길 위 위치 x 1.2초에 켜지고, 나머지 340개는 X 균등, Y 0~0.54, 1.4~3.6초 균등에 켜진다. 반짝임 `tw = 0.35 + 0.65 clip(sin((2 + 3 smoothstep(ramp(t, 11, 12))) t + 위상), 0, 1)^2`, 켜질 때 반짝 `1 + 1.5 exp(-age/0.15)`, 밝기 `clip(age/0.1, 0, 1) tw f_star 반짝`, > 0.85면 `*`, > 0.55면 `+`, 아니면 `.`.
- 별똥별(0~1.2초, 진행 `ease(ramp(t, 0, 1.2))`): 길 마지막 0.35 구간에 30점, 밝기 `linspace(0.1, 1)^2 x 1.2`, 방향 글자, 3줄(오프셋 -0.017, 0, +0.017, 옆 줄은 x 0.6)로 굵게, 색 별 x 1.6, 머리 `@` 별 x 2.4.
- 하늘 칸(Y < 0.59)의 오로라 광선: A > 0.12일 때 A > 0.55면 `|`, > 0.28이면 `:`, 아니면 `.`, 색 `C / A * min(A, 1.3) * f_aur`.
- 호수 반사(0.622 < Y < 0.86 칸): `Y' = 2 x 0.612 - Y`에서 오로라를 계산해 A > 0.2인 곳에 `-` 또는 `~`(`sin(0.9 열 + 2.3 행 + 2t) > 0`으로), 색 `C / A * min(A, 1) * 0.5 f_aur f_land`.
- 별 반사: 켜진 별 중 뒤집은 Y `2 x 0.612 - Y`가 호수 안에 있는 별, X는 `0.006 sin(3t + 4 위상)`만큼 흔들림, 밝기 x 0.5 f_land, 그 줄과 한 줄 아래(x 0.45)에 두 번 그려 잔물결로 늘어진 느낌. 밝기 > 0.4면 `+` 아니면 `.`.

카메라(렌더 화면 전체, 키프레임 시각·배율·초점 X·초점 Y, 사이는 smoothstep): (0, 1.25, 0, 0.68), (1, 1.25, 0, 0.68), (4, 1.0, 0, 0.60), (11, 1.08, 0, 0.30), (12, 1.08, -0.25, 0.32), (12.8, 1.08, 0.25, 0.32), (14.2, 1.0, 0, 0.30), (15, 1.0, 0, 0.30), (16.5, 1.05, 0, 0.30), (18, 1.25, 0, 0.68). 흔들림 없음. 상태 글자, 경과 시간, 코드 패널은 움직이지 않는다.

숫자: `stars` = 켜진 별 수, `bands` = 태어난 지 0.75초 넘은 띠 수, `kp = 1 + 2 ramp(4, 7) + 3 ramp(7, 11) + 2 ramp(12, 12.8) + ramp(12.8, 13.3)` 소수 없이, `letters` = 색 > 0.05인 칸 수.

의도한 것이니 그대로 둔다: 서브스톰 동안 하늘 대부분이 보라와 분홍으로 차고 초록 몸통이 옅어진다. 빛의 파도는 밝은 세로 기둥이 왼쪽에서 오른쪽으로 쓸고 지나가는 모습이다. 첫 프레임과 마지막 프레임은 검정이다.
