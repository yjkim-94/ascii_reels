# 스토리보드: Forest Goddess

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `forest_goddess` |
| 길이 | 18.5초 |
| 한 줄 컨셉 | 황혼의 죽은 숲, 초록 머리칼과 초록 드레스의 숲의 여신이 앙상한 나무로 걸어간다. 발을 디딜 때마다 꽃이 무수히 피어나고, 나무를 만지는 순간 가지마다 잎이 터져 나와 나무가 순식간에 무성해진다 |
| 훅(첫 1초) | 어두운 흙 위에 초록 발자국 하나가 빛나고, 그 자리에서 꽃 한 무더기가 솟아 핀다 |
| 완성 공개 시점 | 여신과 나무 3.5초, 꽃길 9.5초, 손댄 나무 12.0초, 숲 전체 16.6초 |
| 이 영상의 질문 | 여신이 저 마른 나무에 닿으면 어떻게 될까? (답: 나무를 넘어 숲 전체가 되살아난다) |
| 클라이맥스 유형 | 고조·절정형(두 단계: 손댄 나무 -> 숲 전체) |
| 클라이맥스 | 1단계 10.6–12.0초: 손이 닿은 나무에 초록 빛이 번지고 가지마다 잎이 피어오름. 여신이 손을 거두고 나무를 올려다본 뒤(12.0–13.2), 팔을 굽혀 들어 손 사이에 빛을 모았다가(13.2–13.7) 활짝 펼치면(13.7–14.2) 2단계 14.2–16.6초: 발밑에서 초록 빛 고리가 땅을 따라 화면 양 끝까지 퍼지고, 닿는 순서대로 뒤쪽 나무들까지 잎이 돋는다. 대비: 한 그루 -> 숲 전체, 잿빛 땅 -> 초록 땅 |
| 복선 | 발자국마다 피는 꽃(생명이 닿는 곳이 피어남), 손 닿기 직전 껍질의 초록 실핏줄 빛, 1단계 손댄 나무(2단계에서 숲 전체로 커짐) |
| 반복 이음새 | 17.0–18.5초 어두운 황혼으로 페이드(여운 장면 없음), 0초의 어두운 흙과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 5. 연출 설계

| 항목 | 이번 영상에서 |
|---|---|
| 카메라 | 0–1.2초 첫 발자국 클로즈업(1.38 -> 1.3배) -> 1.0–3.5초 빠지며 숲과 나무 공개, 3.5–9.5초 여신 쪽으로 살짝, 9.5–10.6초 손과 줄기 쪽으로 push-in(1.18배), 10.6–12.0초 손댄 나무 쪽으로 빠짐, 12.0–12.6초 팔을 펼치는 여신 쪽으로 다가감(1.08배), 12.6–15.0초 고리가 퍼지는 속도에 맞춰 천천히 빠지며 숲 전체를 보여줌(흔들림 없음), 15–18.5초 거의 고정, 끝은 0초 구도로 복귀 |
| 층 구성 | 배경 황혼 하늘·먼 죽은 숲 / 중경 마른 나무·여신 / 전경 꽃 무더기·마른 풀·떠다니는 꽃잎과 반딧불 |
| 이펙트 | 발자국 빛과 꽃 솟음, 머리칼·드레스 흩날림, 여신의 은은한 빛, 줄기를 타는 초록 실핏줄 빛, 가지 끝 잎 터짐, 잎·꽃잎 날림, 반딧불 |
| 색 변화 | 잿빛 황혼(색은 여신과 꽃뿐) -> 꽃길로 바닥이 물듦 -> 나무가 초록·금으로 -> 하늘 아래쪽 금빛 -> 어둠 |
| 리듬 | 걸음 약 1.2초 간격(일정한 박자), 걸을수록 꽃 무더기가 커짐, 9.5초 멈춤으로 박자를 끊어 긴장, 1단계 1.4초, 0.6초 동작으로 한 번 숨 고르고, 2단계 2.4초 동안 넓게 퍼짐, 여운은 느리게 |
