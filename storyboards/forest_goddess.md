# 스토리보드: Forest Goddess

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `forest_goddess` |
| 길이 | 18초 |
| 한 줄 컨셉 | 황혼의 죽은 숲, 초록 머리칼과 초록 드레스의 숲의 여신이 앙상한 나무로 걸어간다. 발을 디딜 때마다 꽃이 무수히 피어나고, 나무를 만지는 순간 가지마다 잎이 터져 나와 나무가 순식간에 무성해진다 |
| 훅(첫 1초) | 어두운 흙 위에 초록 발자국 하나가 빛나고, 그 자리에서 꽃 한 무더기가 솟아 핀다 |
| 완성 공개 시점 | 여신과 나무 3.5초, 꽃길 9.5초, 무성한 나무 12.2초(68%) |
| 이 영상의 질문 | 여신이 저 마른 나무에 닿으면 어떻게 될까? |
| 클라이맥스 유형 | 변환형 |
| 클라이맥스 | 10.6–13.0초 손이 닿은 곳에서 초록 빛이 줄기를 타고 가지 끝까지 번지고, 가지 끝마다 잎이 터져 나와 앙상한 나무가 1.5초 만에 무성해진다. 앞 장면(앙상한 회갈색 가지, 바닥에만 핀 꽃)과 대비되는 것은 "나무 전체가 한 번에 바뀜"과 "회갈색 -> 초록·금빛" |
| 복선 | 발자국마다 피는 꽃(생명이 닿는 곳이 피어난다), 손이 닿기 직전 껍질에 번지는 초록 실핏줄 빛 |
| 반복 이음새 | 16.5–18.0초 어두운 황혼으로 페이드, 0초의 어두운 흙과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 5. 연출 설계

| 항목 | 이번 영상에서 |
|---|---|
| 카메라 | 0–1.2초 첫 발자국 클로즈업(1.3배) -> 1.0–3.5초 빠지며 숲과 나무 공개, 3.5–9.5초 여신을 따라 천천히 오른쪽으로 이동, 9.5–10.6초 손과 줄기 쪽으로 push-in(1.15배), 10.6–13.0초 잎이 퍼지는 속도에 맞춰 천천히 빠지며 나무 전체를 보여줌(변환형이라 흔들림 없음), 13–16.5초 거의 고정, 끝은 0초 구도로 복귀 |
| 층 구성 | 배경 황혼 하늘·먼 죽은 숲 / 중경 마른 나무·여신 / 전경 꽃 무더기·마른 풀·떠다니는 꽃잎과 반딧불 |
| 이펙트 | 발자국 빛과 꽃 솟음, 머리칼·드레스 흩날림, 여신의 은은한 빛, 줄기를 타는 초록 실핏줄 빛, 가지 끝 잎 터짐, 잎·꽃잎 날림, 반딧불 |
| 색 변화 | 잿빛 황혼(색은 여신과 꽃뿐) -> 꽃길로 바닥이 물듦 -> 나무가 초록·금으로 -> 하늘 아래쪽 금빛 -> 어둠 |
| 리듬 | 걸음 약 0.85초 간격(일정한 박자), 걸을수록 꽃 무더기가 커짐, 9.5초 멈춤으로 박자를 끊어 긴장, 클라이맥스는 1.5초 동안 빠르게, 여운은 느리게 |
