# 스토리보드: Christmas Tree

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `christmas_tree` |
| 길이 | 15초 |
| 한 줄 컨셉 | 빛의 리본이 나선으로 감겨 올라가며 트리를 그리고, 전구가 연쇄로 켜지고, 별이 켜지는 순간 충격파와 불꽃놀이가 터진다 |
| 훅(첫 1초) | 눈 내리는 밤, 땅 한가운데서 반짝이는 빛 머리가 불꽃 꼬리를 끌며 나선으로 솟기 시작한다 |
| 완성 공개 시점 | 트리 형체 4.5초, 전구·장식까지 9.0초(60%) |
| 클라이맥스 | 9.6–12.5초 별 점화 -> 화면을 가로지르는 충격파 -> 트리 뒤로 불꽃 7발 + 전구 색 물결 + `MERRY CHRISTMAS` 금빛 타이핑 |
| 반복 이음새 | 13.5–15.0초 페이드, 밤하늘과 눈만 남아 0초 화면과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / `MERRY CHRISTMAS` |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 밤하늘 | 그림 층(세로 그라데이션) | 전체 | | 진남색, 지평선 쪽 살짝 밝게 |
| 별 | 고정 점 | 하늘 약 150개 | `. + *` | 반짝임 |
| 눈 | 떨어지는 점 2층 | 전체, 뒤 200개 + 앞 80개 | `. * +` | 앞 눈은 트리 앞을 지남, 시작부터 내림 |
| 눈 덮인 땅 | 그림 층 + 2D 마스크 | Y 0.80 아래 | `_ ~ .` | 흰 파랑, 트리 밑 빛 받아 밝아짐 |
| 빛 리본 | 3D 나선 위 움직이는 머리 + 꼬리 | 원뿔 둘레 5바퀴, 아래에서 위로 | 머리 `@`, 꼬리 방향 글자와 `* +` 불티 | 지나간 자리에 트리 잎이 돋음 |
| 트리 | 3D 점 구름 원뿔 4단 | 중심 X 0, Y 0.18~0.76, 밑 반지름 0.42 | 밝기 계단 | 리본이 지나간 높이까지 나타남, 천천히 회전 |
| 줄기 | 3D 점 구름 | 트리 밑 Y 0.76~0.80 | 밝기 계단 | 갈색 |
| 금빛 가랜드 | 방향 글자 선 | 원뿔 표면 나선 | `\| / \ -` | 리본이 남긴 궤적이 그대로 가랜드가 됨 |
| 전구 480개 | 원뿔 표면 점 | 나선 3가닥 | `* +` | 아래에서 위로 연쇄 점등, 켜질 때 작은 불티 |
| 장식 공 60개 | 크기가 다른 글자(스프라이트) | 원뿔 표면 | `o O @` | 튀어나오며 둥근 빛 고리, 반짝임 |
| 꼭대기 별 | 2D 오각별 + 빛줄기 | 트리 꼭대기 | `* @`, 방향 글자 | 클라이맥스 시작에 점화 |
| 충격파 | 퍼지는 원 | 별에서 화면 끝까지 | `. o O` | 한 번 |
| 불꽃놀이 7발 | 입자 폭발 + 중력 + 꼬리 | 트리 뒤 하늘 | `. * + '` | 색 다양, 터지기 전 올라가는 궤적 |
| 문구 | 큰 글씨 자막 | Y 0.835 | | `MERRY CHRISTMAS`, 금빛, 타이핑 + 불티 |

## 3. 팔레트

| 이름 | 용도 | RGB(0~1) |
|---|---|---|
| bg | 밤하늘 위 / 지평선 | (0.01, 0.02, 0.08) / (0.04, 0.07, 0.22) |
| main | 트리 에메랄드 | (0.10, 0.75, 0.35) |
| ribbon | 리본·가랜드·별·문구 | 금 (1.00, 0.82, 0.35) |
| bulbs | 전구 | 금 (1.0, 0.82, 0.35), 빨강 (1.0, 0.20, 0.20), 흰 (1.0, 0.95, 0.85) |
| ornaments | 장식 공 | 빨강, 금, 은 (0.85, 0.88, 0.95), 파랑 (0.30, 0.50, 1.00) |
| fireworks | 불꽃 | 빨강, 금, 초록, 하늘, 분홍, 보라, 흰 |
| snow | 눈, 땅 | (0.85, 0.90, 1.00) |

색 전환: 전구가 켜지면서 트리가 초록에서 따뜻한 빛으로 물든다. 클라이맥스에는 전구 색이 아래에서 위로 물결치며 바뀌고(금 -> 빨강 -> 흰 -> 금), 불꽃이 터질 때마다 하늘이 그 색으로 잠깐 물든다.
