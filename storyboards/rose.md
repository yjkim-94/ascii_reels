# 스토리보드: Rose

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `rose` |
| 길이 | 15초 |
| 한 줄 컨셉 | 땅에서 줄기가 자라 잎을 펴고, 봉오리가 맺혀 큰 진홍 장미가 활짝 핀다 |
| 훅(첫 1초) | 흩어진 빛 입자 400여 개가 소용돌이치며 땅의 한 점으로 빨려 들어가고, 그 자리에서 흙이 튀며 줄기 끝이 솟는다 |
| 완성 공개 시점 | 줄기·잎 4.0초, 봉오리 5.5초, 만개 10.0초(67%) |
| 클라이맥스 | 10.0–12.0초 만개 순간 꽃 중심에서 금빛 빛이 터지고 꽃가루가 흩날린다 |
| 반복 이음새 | 13.5–15.0초 페이드, 흐린 빛 입자만 남아 0초 화면과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 빛 입자 | 고정 점, 천천히 떠오름 | 화면 전체 약 170개 | `. +` | 흐린 따뜻한 색, 반짝임 |
| 수렴 입자 | 점 420개 | 땅 위 반지름 0.25~0.8에서 땅의 한 점으로 | `. + *` | 0~1.2초 훅 |
| 땅 | 2D 마스크 | Y 0.83 얇은 띠 | `_ .` | 흐린 갈색, 시작부터 보임 |
| 줄기 | 3D 점 구름(가는 관) | 아래 (0, 0.83)에서 위 (0, 0.40)까지 완만한 S자 | 밝기 계단 | 아래에서 위로 자람, 가시 6개(`< >`) |
| 잎 2장 | 3D 점 구름(곡면) | 줄기 중간 좌우, 길이 0.16 | 밝기 계단 | 접혀 있다 펼쳐짐, 가운데 잎맥 밝게 |
| 꽃받침 | 3D 점 구름 | 봉오리를 감싼 5장 | 밝기 계단 | 봉오리가 열리기 전에 아래로 젖혀짐 |
| 꽃잎 | 3D 점 구름(곡면) 34장 | 꽃 중심 (0, 0.36), 만개 반지름 약 0.40 | 밝기 계단 | 5겹(3, 5, 7, 9, 10장), 바깥 겹부터 펼쳐짐, 꽃 전체 천천히 회전, 앞으로 약 25도 기울임 |
| 빛줄기 | 방향 글자 선 | 꽃 중심에서 방사 | `\| / \ -` | 클라이맥스에만 |
| 꽃가루 | 점(입자) 320개 | 중심에서 퍼져 위로 떠오름 | `. * +` | 클라이맥스부터 |

## 3. 팔레트

| 이름 | 용도 | RGB(0~1) |
|---|---|---|
| bg | 배경 검정, 빛 입자 | 입자 (0.25, 0.12, 0.12) 흐리게 |
| main | 꽃잎 바깥 진홍 / 안쪽 다홍 | (0.78, 0.05, 0.15) / (1.00, 0.25, 0.35) |
| accent | 꽃잎 가장자리 테두리광 | 연분홍 (1.00, 0.60, 0.70) |
| green | 줄기·잎 / 꽃받침 | (0.12, 0.45, 0.18) / (0.20, 0.55, 0.25) |
| after | 클라이맥스 빛·꽃가루 | 금 (1.00, 0.82, 0.40) |

색 전환: 봉오리는 짙은 진홍, 펼쳐질수록 안쪽 다홍이 드러남. 클라이맥스에 중심부터 금빛이 번지고 꽃잎 가장자리가 연분홍으로 빛남.
