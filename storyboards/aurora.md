# 스토리보드: Aurora

## 1. 기본

| 항목 | 값 |
|---|---|

| 길이 | 18초 |
| 한 줄 컨셉 | 칠흑 같은 밤, 별똥별 하나가 별들을 켜고, 얼어붙은 호수 위로 오로라 띠가 한 가닥씩 자라나 하늘을 덮은 뒤, 지평선 끝에서 시작된 빛의 파도가 커튼 전체를 깨워 오로라가 하늘 꼭대기까지 치솟으며 춤춘다(서브스톰) |

| 반복 이음새 | 16.5–18.0초 오로라 -> 별 -> 어둠 순으로 사라져 0초의 칠흑과 같다 |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 밤하늘 | 그림 층(세로 그라데이션 + 흐린 은하수 노이즈) | Y 0~0.60 | | 진남 -> 지평선 쪽 조금 밝게 |
| 별 | 점 | 하늘 400개 | `. + *` | 별똥별이 지나간 자리부터 켜짐, 반짝임 |
| 별똥별 | 방향 글자 선 + 빛 | 하늘을 가로지름 | `\ / -` | 훅 1개, 클라이맥스 3개 |
| 침엽수 숲 | 그림 층 실루엣 + 눈 덮인 끝 | 지평선 Y 0.60 위로 뾰족뾰족 | 끝에 `^ .` | 검은 실루엣 |
| 얼음 호수 | 그림 층(어두운 수면) + 반사 | Y 0.62~0.85 | 비친 별 `. +`(잔물결로 세로로 살짝 늘어짐), 비친 오로라 `- ~` | 하늘의 별과 오로라가 위아래 뒤집혀 비침, 잔물결로 일렁임. 금 간 얼음은 넣지 않음 |
| 오로라 띠 5개 | 그림 층(부드러운 빛) + 글자 격자(세로 광선) | 하늘 Y 0.05~0.58, 띠마다 높이·물결이 다름 | 세로 광선 `\| : .` | 아래 가장자리 밝은 초록, 위로 갈수록 보라·분홍으로 옅어짐, 커튼처럼 너울대고 광선이 옆으로 흐름 |
| 빛의 파도 | 그림 층 밝기 + 글자 밝기 | 왼쪽 지평선에서 오른쪽으로 띠를 따라 이동 | 띠의 광선 글자가 순간 `\|`로 굵어지고 밝아짐 | 클라이맥스 시작 신호 |
| 서브스톰 커튼 | 그림 층 + 세로 광선 글자 | 기존 띠 5개가 커져 지평선에서 하늘 꼭대기까지 | `\| : .` | 커튼이 S자로 접히고 일렁임이 빨라짐, 광선이 위로 길게 솟음, 아래 가장자리 분홍 |

## 3. 팔레트

| 이름 | 용도 | RGB(0~1) |
|---|---|---|
| bg | 하늘 위 / 지평선 | (0.01, 0.02, 0.06) / (0.04, 0.07, 0.16) |
| stars | 별, 눈 | (0.85, 0.90, 1.00) |
| green | 오로라 아래 가장자리 / 몸통 | (0.35, 1.00, 0.60) / (0.10, 0.80, 0.45) |
| violet | 오로라 위쪽 | (0.60, 0.30, 0.95) |
| pink | 서브스톰 때 커튼 아래 가장자리 | (1.00, 0.40, 0.70) |
| ice | 얼음 호수 | (0.05, 0.10, 0.18), 금 간 선 (0.55, 0.75, 1.00) |

색 전환: 처음엔 흑백에 가까운 별빛만. 띠가 늘수록 하늘이 초록으로 물들고 위쪽에 보라가 번진다. 클라이맥스에 빛의 파도가 지나간 커튼부터 아래 가장자리가 분홍으로 타오르고, 광선 위쪽은 보라가 하늘 꼭대기까지 번진다. 호수도 같은 색으로 바뀐다. 여운에서 다시 부드러운 초록으로 가라앉는다.

## 5. 연출 설계

| 항목 | 이번 영상에서 |
|---|---|
| 카메라 | 1.0–4.0초 호수 반사 클로즈업(1.25배)에서 빠지며 풍경 공개, 4.0–11.0초 하늘 쪽으로 천천히 올려다보며 1.08배까지 다가감, 12.0–14.0초 빛의 파도를 따라 왼쪽에서 오른쪽으로 살짝 이동한 뒤 천천히 빠지며(1.08 -> 1.0) 하늘 꼭대기까지 솟은 커튼 전체를 보여줌(흔들림 없음, 장엄하게), 15.0초 이후 천천히 다가감, 끝은 0초 구도로 복귀 |
| 층 구성 | 배경 은하수·별 / 중경 오로라 커튼·숲 / 전경 호수에 비친 별과 오로라 |
| 이펙트 | 별똥별 꼬리, 별 켜짐(호수 반사 포함), 오로라 세로 광선 흐름, 빛의 파도, 커튼 S자 접힘과 빠른 일렁임, 분홍 가장자리, 호수 반사 일렁임 |
| 색 변화 | 흑백 별빛 -> 남색 풍경 -> 초록 하늘 -> 위쪽 보라 -> 정적(살짝 어두움) -> 빛의 파도 -> 분홍 가장자리와 하늘 꼭대기 보라 -> 부드러운 초록 -> 어둠 |
| 리듬 | 띠가 1초 간격으로 하나씩 추가, 커튼 너울 약 3초 주기 -> 서브스톰 때 약 1초 주기로 빨라짐 -> 여운에서 다시 느려짐. 11~12초 정적은 대비를 위한 의도(별 반짝임은 유지) |
