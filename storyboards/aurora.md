# 스토리보드: Aurora

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `aurora` |
| 길이 | 18초 |
| 한 줄 컨셉 | 칠흑 같은 밤, 별똥별 하나가 별들을 켜고, 얼어붙은 호수 위로 오로라 띠가 한 가닥씩 자라나 하늘을 덮은 뒤, 머리 위 한 점에서 빛이 터지며(코로나) 하늘 전체가 초록·보라·분홍 물결로 뒤덮인다 |
| 훅(첫 1초) | 완전한 어둠 속을 별똥별 하나가 가로지르고, 지나간 자리마다 별이 하나씩 켜진다 |
| 완성 공개 시점 | 풍경 4.0초, 오로라 띠 5개 완성 11.0초(61%) |
| 클라이맥스 | 12.0–15.0초 오로라가 머리 위 한 점으로 모였다가 사방으로 터지는 코로나, 색 물결이 하늘을 휩쓸고 호수에 그대로 비침, 별똥별 연속 |
| 반복 이음새 | 16.5–18.0초 오로라 -> 별 -> 어둠 순으로 사라져 0초의 칠흑과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 밤하늘 | 그림 층(세로 그라데이션 + 흐린 은하수 노이즈) | Y 0~0.60 | | 진남 -> 지평선 쪽 조금 밝게 |
| 별 | 점 | 하늘 400개 | `. + *` | 별똥별이 지나간 자리부터 켜짐, 반짝임 |
| 별똥별 | 방향 글자 선 + 빛 | 하늘을 가로지름 | `\ / -` | 훅 1개, 클라이맥스 3개 |
| 침엽수 숲 | 그림 층 실루엣 + 눈 덮인 끝 | 지평선 Y 0.60 위로 뾰족뾰족 | 끝에 `^ .` | 검은 실루엣 |
| 얼음 호수 | 그림 층(어두운 얼음) + 반사 | Y 0.62~0.85 | 금 간 얼음 `/ \ -`, 반짝임 `'` | 하늘과 오로라가 위아래 뒤집혀 비침, 잔물결 노이즈로 일렁임 |
| 오로라 띠 5개 | 그림 층(부드러운 빛) + 글자 격자(세로 광선) | 하늘 Y 0.05~0.58, 띠마다 높이·물결이 다름 | 세로 광선 `\| : .` | 아래 가장자리 밝은 초록, 위로 갈수록 보라·분홍으로 옅어짐, 커튼처럼 너울대고 광선이 옆으로 흐름 |
| 코로나 | 방향 글자 광선 + 그림 층 빛 | 머리 위 한 점(화면 위쪽 가운데)에서 사방으로 | `\| / \ -` | 클라이맥스에만 |

## 3. 팔레트

| 이름 | 용도 | RGB(0~1) |
|---|---|---|
| bg | 하늘 위 / 지평선 | (0.01, 0.02, 0.06) / (0.04, 0.07, 0.16) |
| stars | 별, 눈 | (0.85, 0.90, 1.00) |
| green | 오로라 아래 가장자리 / 몸통 | (0.35, 1.00, 0.60) / (0.10, 0.80, 0.45) |
| violet | 오로라 위쪽 | (0.60, 0.30, 0.95) |
| pink | 클라이맥스 가장자리 | (1.00, 0.40, 0.70) |
| ice | 얼음 호수 | (0.05, 0.10, 0.18), 금 간 선 (0.55, 0.75, 1.00) |

색 전환: 처음엔 흑백에 가까운 별빛만. 띠가 늘수록 하늘이 초록으로 물들고 위쪽에 보라가 번진다. 클라이맥스에 분홍 물결이 하늘을 휩쓸고 호수도 같은 색으로 바뀐다.

## 5. 연출 설계

| 항목 | 이번 영상에서 |
|---|---|
| 카메라 | 1.0–4.0초 호수 반사 클로즈업(1.25배)에서 빠지며 풍경 공개, 4.0–11.0초 하늘 쪽으로 천천히 올려다보며 1.08배까지 다가감, 12.0초 코로나 순간 1.08 -> 1.0으로 확 빠지며 살짝 흔들림, 15.0초 이후 천천히 다가감, 끝은 0초 구도로 복귀(어둠이라 이음새 없음) |
| 층 구성 | 배경 은하수·별 / 중경 오로라 띠·숲 / 전경 얼음 호수와 반사, 얼음 반짝임 |
| 이펙트 | 별똥별 꼬리, 별 켜짐, 오로라 세로 광선 흐름, 코로나 광선, 색 물결, 호수 반사 일렁임 |
| 색 변화 | 흑백 별빛 -> 남색 풍경 -> 초록 하늘 -> 위쪽 보라 -> 분홍 물결 -> 어둠 |
| 리듬 | 띠가 1초 간격으로 하나씩 추가, 커튼 너울 약 3초 주기, 정지 구간 없음 |
