# 스토리보드: Summoning

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `summoning` |
| 길이 | 20초 |
| 한 줄 컨셉 | 안개 낀 음산한 들판, 땅에 금빛 마법진이 그려지고 네 마법사가 각자의 속성(불·물·바람·대지)을 불어넣어 중앙에서 불사조를 소환한다 |
| 훅(첫 1초) | 어둠과 안개 속, 하늘에서 금빛 불씨 하나가 떨어져 땅에 닿는 순간 마법진의 첫 원이 불꽃처럼 그어지기 시작한다 |
| 완성 공개 시점 | 마법진 5.0초, 네 속성 모두 연결 11.0초(55%) |
| 클라이맥스 | 13.0–16.5초 빛의 기둥을 뚫고 거대한 불사조가 날개를 펼치며 솟아오름, 불티 충격파, 꼬리깃이 네 속성 색으로 흩날림 |
| 반복 이음새 | 18.5–20.0초 불사조가 불티로 흩어지며 페이드, 안개와 어두운 하늘만 남아 0초 화면과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 하늘 | 그림 층(그라데이션 + 노이즈 구름) | Y 0~0.45 | | 보라빛 검정, 먹구름이 천천히 소용돌이, 지평선에 옅은 붉은 기운 |
| 먼 지평선 | 그림 층 실루엣 | Y 0.45 부근 | | 뾰족한 바위산·죽은 나무 실루엣 |
| 안개 | 그림 층 노이즈 + 흐린 글자 | 바닥 Y 0.45~0.85 | `~ . -` | 낮게 깔려 천천히 흐름, 음산함 |
| 마법진 | 바닥 평면 원근(`ground`) 위 방향 글자 선 | 중심 화면 (0, 0.66), 가로 폭 약 1.5(화면 폭의 75%) 타원 | `\| / \ - o` | 바깥 원, 안쪽 원, 육망성, 네 방위 속성 문양, 원 띠의 룬 72개. 천천히 회전 |
| 룬 | 크기가 다른 글자(스프라이트) | 마법진 띠를 따라 72개 | 영문 대문자·기호(`R Z A X ^ < > ...`) | 하나씩 새겨지며 빛남 |
| 마법사 4명 | 2D 실루엣(두건 쓴 로브) + 지팡이 끝 빛 | 마법진 둘레 네 방위, 뒤 2명 작게, 앞 2명 크게(원근) | 어두운 로브 `#`, 가장자리 속성색 테두리광 | 안개에서 서서히 드러나 지팡이를 듦 |
| 속성 마법 | 입자·방향 글자 선 | 각 마법사 지팡이 -> 마법진 중앙 | 불 `^ * '`, 물 `~ o .`, 바람 `( ) ~`, 대지 `# A ^` | 불: 휘감는 화염 / 물: 나선 물줄기 / 바람: 소용돌이 띠 / 대지: 솟는 수정 조각 |
| 빛의 기둥 | 세로 방향 글자 + 그림 층 빛 | 마법진 중앙에서 하늘로 | `\|` | 네 속성 합쳐질 때, 흰빛 |
| 불사조 | 3D 점 구름(몸통·날개·꼬리) | 중앙 위 Y 0.12~0.5, 날개 폭 약 1.6(화면 폭의 80%) | 밝기 계단 | 불꽃 글자로 이루어짐, 날갯짓, 꼬리깃 네 속성 색 |
| 불티 | 입자 | 불사조 주변·하늘 | `. * '` | 충격파와 함께 퍼지고 떨어짐 |

색 전환: 처음엔 금빛 마법진만 빛나는 음산한 어둠. 속성이 하나씩 깨어날 때마다 그 사분면과 하늘이 그 색으로 물든다. 융합 때 흰빛, 불사조 등장과 함께 화면 전체가 불꽃색으로 타오른다.
