# 스토리보드: Summoning

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `summoning` |
| 길이 | 20초 |
| 한 줄 컨셉 | 안개 낀 음산한 들판, 네 마법사가 차례로 지팡이를 들어 발밑에 자기 속성(불·물·바람·대지)의 마법진을 그리고 마법을 일으킨다. 네 힘이 중앙으로 모여 금빛 대마법진이 완성되고 불사조가 소환된다 |
| 훅(첫 1초) | 어둠과 안개 속, 하늘에서 금빛 불씨 하나가 떨어져 들판 중앙에 닿는 순간 희미한 금빛 고리가 번지며 안개가 밀려난다 |
| 완성 공개 시점 | 네 속성 마법진 11.0초(55%), 중앙 대마법진 12.5초(62%) |
| 클라이맥스 | 13.0–16.5초 빛의 기둥을 뚫고 거대한 불사조가 날개를 펼치며 솟아오름, 불티 충격파, 꼬리깃이 네 속성 색으로 흩날림 |
| 반복 이음새 | 18.5–20.0초 불사조가 불티로 흩어지며 페이드, 안개와 어두운 하늘만 남아 0초 화면과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 하늘 | 그림 층(그라데이션 + 노이즈 구름) | Y 0~0.45 | | 보라빛 검정, 먹구름이 천천히 소용돌이, 지평선에 옅은 붉은 기운 |
| 먼 지평선 | 그림 층 실루엣 | Y 0.45 부근 | | 뾰족한 바위산·죽은 나무 실루엣 |
| 안개 | 그림 층 노이즈 + 흐린 글자 | 바닥 Y 0.45~0.85 | `~ . -` | 낮게 깔려 천천히 흐름, 음산함 |
| 속성 마법진 4개 | 바닥 평면 원근(`ground`) 위 방향 글자 선 | 각 마법사 발밑, 반지름 0.45(원근 때문에 뒤 2개 작게, 앞 2개 크게) | `\| / \ - o` | 마법사가 지팡이를 들면 지팡이 끝 빛을 따라 원 -> 속성 문양(불 삼각, 물 물결, 바람 소용돌이, 대지 사각) -> 룬 18개 순으로 그려짐, 속성색 |
| 중앙 대마법진 | 바닥 평면 원근 위 방향 글자 선 | 중심 화면 (0, 0.66), 가로 폭 약 1.0 타원 | `\| / \ - o` | 네 속성 빛이 모이며 금빛으로 그려짐: 바깥 원, 안쪽 원, 육망성, 네 작은 마법진과 잇는 선. 천천히 회전 |
| 룬 | 크기가 다른 글자(스프라이트) | 속성 마법진마다 18개, 합 72개 | 영문 대문자·기호(`R Z A X ^ < > ...`) | 지팡이 빛이 지나가며 하나씩 새겨짐 |
| 마법사 4명 | 2D 실루엣(두건 쓴 로브) + 지팡이 끝 빛 | 중앙을 둘러싼 네 방위(뒤 왼쪽·뒤 오른쪽 작게, 앞 왼쪽·앞 오른쪽 크게, 원근) | 어두운 로브 `#`, 가장자리 속성색 테두리광 | 안개에서 서서히 드러남, 자기 차례에 지팡이를 들어 원을 그리듯 휘두름 |
| 속성 마법 | 입자·방향 글자 선 | 각 속성 마법진 위에서 솟고, 끝나면 빛줄기가 중앙으로 | 불 `^ * '`, 물 `~ o .`, 바람 `( ) ~`, 대지 `# A ^` | 불: 마법진에서 화염 회오리 / 물: 나선 물기둥 / 바람: 소용돌이 바람 띠와 잎 / 대지: 수정 조각이 솟구침 |
| 빛의 기둥 | 세로 방향 글자 + 그림 층 빛 | 마법진 중앙에서 하늘로 | `\|` | 네 속성 합쳐질 때, 흰빛 |
| 불사조 | 3D 점 구름(몸통·날개·꼬리) | 중앙 위 Y 0.12~0.5, 날개 폭 약 1.6(화면 폭의 80%) | 밝기 계단 | 불꽃 글자로 이루어짐, 날갯짓, 꼬리깃 네 속성 색 |
| 불티 | 입자 | 불사조 주변·하늘 | `. * '` | 충격파와 함께 퍼지고 떨어짐 |

## 5. 연출 설계

| 항목 | 이번 영상에서 |
|---|---|
| 카메라 | 0~2.6초 중앙 바닥 클로즈업(1.18배)에서 빼며 들판 공개, 마법사 차례마다 그 마법사 쪽으로 push-in(1.14배), 11~13초 하늘 쪽으로 틸트하며 확대, 13.3초 불사조 충격 때 흔들림, 14~18.5초 불사조 쪽으로 천천히 다가가며 살짝 기울임, 끝은 0초 구도로 복귀 |
| 층 구성 | 배경 하늘·먹구름·바위산 / 중경 마법사·마법진·불사조 / 전경 안개·불티 |
| 이펙트 | 불씨 꼬리·봉인 고리·불티, 속성 마법 입자, 빛의 기둥, 섬광·충격파, 불사조 깃털과 불티 |
| 색 변화 | 보라빛 어둠 -> 속성마다 주변과 하늘이 그 색 -> 흰빛 -> 불꽃색 |
| 리듬 | 2초 단위 속성 시전, 불사조 날갯짓 1초 주기 |
