> 이 파일을 먼저 채우고 사람이 승인한 뒤에 코드를 쓴다. 코드는 이 표를 그대로 옮긴다.
> 좌표: 위쪽 화면 기준 X는 -1(왼쪽)~1(오른쪽), Y는 0(위)~1(아래). 하단 0.85 아래는 HUD 자리.

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `<영문_소문자>` |
| 길이 | <=20초 |
| 한 줄 컨셉 | 예: 씨앗이 싹을 틔워 꽃이 피고 꽃잎이 흩날린다 |
| 훅(첫 1초) | 첫 1초 안에 무엇이 움직이며 궁금증을 만드는가 |
| 완성 공개 시점 | 형체가 다 드러나는 시각(전체의 55~70% 권장) |
| 클라이맥스 | 마지막 한 방. 무엇이, 몇 초에 |
| 반복 이음새 | 끝 화면이 첫 화면과 어떻게 같아지는가 |
| 소스 영상(실사 변환 시) | 파일, 출처, 쓸 구간 |
| 계정 / 문구 | `@justmade.lab` / 화면에 타이핑할 문구(없으면 없음) |

## 5. HUD

3줄 이내. 1줄: 계정. 2~3줄: 줄거리를 따라 올라가는 숫자 2~4개(예: `petals 0 -> 24`).

## 6. 사람 검수 (점검 시트 `out/<slug>_check.png`를 보고)
