# 스토리보드: Saturn

## 1. 기본

| 항목 | 값 |
|---|---|
| slug (파일 이름) | `saturn` |
| 길이 | 15초 |
| 한 줄 컨셉 | 흩어진 먼지가 모여 행성이 되고, 적도에서 입자가 퍼져 고리가 된다 |
| 훅(첫 1초) | 별이 반짝이는 어둠 속에서 먼지 소용돌이가 돌며 안으로 말려 들어가기 시작 |
| 완성 공개 시점 | 행성 4.5초, 고리 완성 9.5초(63%) |
| 클라이맥스 | 9.5–12.0초 역광: 태양이 행성 뒤에서 떠오르며 고리가 금빛으로 빛나고 행성은 테두리만 빛남 |
| 반복 이음새 | 13.5–15.0초 페이드, 별만 남아 0초 화면과 같다 |
| 소스 영상(실사 변환 시) | 없음(코드로 생성) |
| 계정 / 문구 | `@justmade.lab` / 없음 |

## 2. 오브젝트

| 이름 | 표현 방식 | 위치·크기 | 글자 재료 | 비고 |
|---|---|---|---|---|
| 별 | 고정 점 | 화면 전체, 약 180개 | `. + *` | 점마다 다른 박자로 반짝 |
| 먼지 | 3D 점 구름 | 반지름 0.9 소용돌이 -> 행성 표면 | `. , +` -> 밝기 계단 | 4,812개, 나선으로 회전하며 수축 |
| 행성 | 3D 점 구름 + `light` | 중심 (0, 0.42), 반지름 0.28, 극 쪽 10% 납작 | 밝기 계단 | 위도 띠 무늬, 자전 |
| 고리 | 3D 점 구름(입자) | 반지름 1.24~2.27배(0.35~0.64), 카시니 간극 | 밝기 계단 | 12,000개, 안쪽이 더 빨리 돎 |
| 고리 그림자 | 밝기 조절 | 행성 뒤 그림자 기둥 안 고리 입자 | | 행성이 고리에 드리우는 그림자 |
| 태양 | 점 + 방향 글자 빛줄기 | 행성 왼쪽 위 뒤편에서 떠오름 | `@ * \| - \ /` | 클라이맥스 때만 |

## 3. 팔레트

| 이름 | 용도 | RGB(0~1) |
|---|---|---|
| bg | 배경(검정), 별 | 별 (0.60, 0.65, 0.80) 흐리게 |
| main | 행성 띠 | 호박 (0.95, 0.62, 0.28), 크림 (1.00, 0.88, 0.65), 짙은 띠 (0.70, 0.45, 0.25) |
| ring | 고리 | 베이지 (0.90, 0.82, 0.65) |
| after | 역광 | 흰 (1.0, 1.0, 1.0), 금 (1.00, 0.85, 0.45) |

색 전환: 클라이맥스(9.5–12.0초)에 조명이 앞에서 뒤로 돌며 호박·크림 -> 흰·금. 고리 바깥쪽부터 빛남.
