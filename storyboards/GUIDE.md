# 기획 가이드

기획자 인터뷰(2026-11-21)로 정한 기준과, 레퍼런스 4개에서 뽑은 연출 패턴.
`/new-reel`은 인터뷰와 스토리보드 초안을 이 문서 기준으로 만든다.

## 1. 고정 기준

| 항목 | 기준 |
|---|---|
| 계정 표기 | `@justmade.lab` |
| 길이 | 최대 15초(엔진이 거부), 보통 12~15초 |
| 분위기 | 고정 톤 없음. 주제마다 정한다 |
| 팔레트 | 색 수 제한 없음. 주제에 맞게 |
| 문구 | 주제에 맞을 때만(기념일, 인사 등). 기본은 형체 완성이 클라이맥스 |
| 문구 언어 | 영문만 |
| 코드 패널 | 항상 표시 |
| 상태 글자 | 항상. 1줄 계정 + 줄거리를 따라 오르는 주제별 숫자 2~4개 |
| 주제 범위 | 자연·생물, 계절·기념일, 사물·보석, 우주·추상 |
| 제작 방식 | 코드로 형체 만들기(2D 마스크, 3D 점 구름) + 실사 영상 글자 변환 |

## 2. 인터뷰 (핵심 4문항)

질문마다 **AI가 먼저 예시 3개를 제시**하고(추천 1개 표시) 기획자가 고르거나 고쳐 쓴다.
나머지 항목(훅, 오브젝트 배치, 장면 시간, 배경)은 AI가 스토리보드 초안에서 정하고 기획자가 표에서 고친다.

1. **컨셉과 클라이맥스**: 무엇이 어떻게 완성되고, 마지막 한 방은 무엇인가
   - 예(해파리): 불씨가 모여 갓이 생기고 촉수가 자라 헤엄친다 / 클라이맥스: 박동마다 색 물결이 몸을 타고 흐름
2. **분위기와 색**: 배경 톤, 주색, 강조색, 색 전환을 넣을지
   - 예: 심해 남색 배경 + 형광 파랑, 전환 후 분홍·청록
3. **문구**: 넣을지, 넣는다면 영문 문구와 등장 시점
   - 예: 없음 / `MERRY CHRISTMAS 2026` 9.4초부터 타이핑
4. **상태 숫자**: 줄거리를 따라 오를 숫자 2~4개
   - 예: `beats`, `tentacles`, `colours`, `letters`

## 3. 연출 패턴 목록 (장면표를 짤 때 고른다)

| 패턴 | 설명 | 레퍼런스 | 엔진 기능 |
|---|---|---|---|
| 아래에서 자라기 | 형체가 바닥부터 위로 드러남, 끝선이 반짝 | 트리 | 2D 마스크 + `smooth` |
| 불씨 모이기 | 흩어진 `+ *`가 모여 윤곽이 됨 | 해파리 | 점 위치를 시간으로 보간 |
| 하나씩 튀어나오기 | 장식·꽃잎이 순서대로 커졌다 자리잡음 | 트리 | `pop` |
| 박동·호흡 | 수축 후 이완, 부위별 시차 | 해파리 | 시간 지연 `t - LAG * u` |
| 색 물결 | 흰 띠가 몸을 타고 흐르며 팔레트 교체 | 해파리 | 해파리 시안 `colour_wave` |
| 회전 공개 | 천천히 돌며 입체감, 앞뒤 가림 | 트리, 반지 | `rot_y`, `splat` |
| 광택·반짝임 | 주광 + 도는 테두리광 + 짧은 번쩍임 | 반지 | `light` |
| 빛줄기 | 꼭대기에서 뻗는 선 | 트리, 반지 | `dir_chars` |
| 바닥 반사 | 아래에 흐린 거울상 | 반지 | `splat_reflection` |
| 문구 타이핑 | 자간 넓힌 큰 글씨, 깜빡 커서 | 트리 | `caption` |
| 주제 단어로 채우기 | 형체를 주제 단어 글자로 채움 | 트리 | `idx(WORD)` |
| 실사 글자화 | 실사 영상의 밝기·색을 글자로 | 꽃 | `Footage`, `draw_footage` |
| 배경 층 | 흐린 글자비, 눈, 먼 실루엣 | 전부 | `LetterRain`, `Snow`, 작은 `splat` |
| 페이드 루프 | 끝에서 배경만 남겨 첫 화면과 같게 | 전부 | `ease` |

## 4. 실사 영상 소스 규칙

- 직접 찍은 영상, 직접 만든 영상, 이용 허락이 분명한 소스만 쓴다. 출처를 스토리보드 기본 항목에 적는다.
- 어두운 배경에 피사체가 밝은 영상이 잘 나온다(어두운 칸은 비워진다).
- 원본은 `sources/`에 두고, 15초보다 길면 쓸 구간을 스토리보드에 적는다.
