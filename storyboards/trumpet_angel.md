# 스토리보드: Trumpet Angel

> 이 파일을 먼저 채우고 사람이 승인한 뒤에 코드를 쓴다. 코드는 이 표를 그대로 옮긴다.
> 좌표: 위쪽 화면 기준 X는 -1(왼쪽)~1(오른쪽), Y는 0(위)~1(아래). 하단 0.85 아래는 HUD 자리.
> 위쪽 화면은 1080x1098px라 X 1 = 540px, Y 1 = 1098px. 글자 한 칸은 X 약 0.019, Y 약 0.016.

## 2. 오브젝트

천사 자세는 레퍼런스를 따른다: 구름 위에 앉아 몸은 정면에서 살짝 돌아가 있고, 고개를 젖혀 왼쪽 위를 본다.
오른손(화면 왼쪽 손)을 들어 나팔을 잡고, 나팔은 입에서 왼쪽 위로 수평보다 약 22도 올라간다.
양 날개는 어깨 위로 들렸지만 반쯤만 펼쳐져 있다. 왼 무릎(화면 왼쪽)은 들려 있고 오른 다리는 구름 아래로 내려와 발끝이 보인다.

## 5. 연출 설계

| 항목 | 이번 영상에서 | 비고 |
|---|---|---|
| 카메라 | 고정 풀샷. 이유: 기획자 요청(풀샷 고정, 살짝 멀리서). 스테인드글라스는 창 전체가 한 장의 그림이라 구도가 같아야 조각이 채워지는 과정이 읽힌다. 움직임은 음파와 깃털이 맡는다 | `camera` 쓰지 않음 |
| 층 구성 | 배경: 어둠 + 창틀·하늘 유리 / 중경: 천사·구름 유리 / 전경: 금빛 음파, 떨어지는 깃털, 빛줄기와 먼지 | 깃털과 음파는 유리 위를 지나감 |
| 이펙트 | 금빛 음파(빛 번짐), 음파가 지날 때 납선 반짝임, 유리가 켜지는 0.4초 밝기 오버슛, 클라이맥스 뒤 역광 밝기 상승과 빛줄기, 먼지 | 섬광·흔들림 없음 |
| 색 변화 | 검정 -> 금(나팔) -> 살색·진주·상아(천사) -> 진홍(옷 단) -> 연금빛(구름) -> 청금석·에메랄드(배경·창틀) -> 전체 밝음 -> 검정 | 천사는 따뜻한 색, 배경은 차가운 색 |
| 리듬 | 음파 약 1.4초 간격으로 일정하게 반복, 10.0–11.3초 한 번 멈춰 박자를 끊고, 클라이맥스 음파는 두께 2배, 1.2초에 걸쳐 화면 끝까지. 깃털 낙하는 음파와 엇박. 1초 이상 멈춘 화면 없음(정적 구간에도 깃털·맥동·날개) | |

## 6. HUD

1줄 `@justmade.lab`
2줄 `feathers 22   notes 11   rays 5`
3줄 `panes N`

- `notes`: 퍼진 음파 수(클라이맥스 포함 11)
- `feathers`: 떨어지기 시작한 깃털 수(22)
- `rays`: 내려온 빛줄기 수(5)
- `panes`: 켜진 유리 조각 수(0 -> 176)
