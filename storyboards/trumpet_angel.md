# 스토리보드: Trumpet Angel

> 이 파일을 먼저 채우고 사람이 승인한 뒤에 코드를 쓴다. 코드는 이 표를 그대로 옮긴다.
> 좌표: 위쪽 화면 기준 X는 -1(왼쪽)~1(오른쪽), Y는 0(위)~1(아래). 하단 0.85 아래는 HUD 자리.
> 천사 자세(몸 방향, 나팔 각도, 날개 모양)는 레퍼런스 이미지를 받으면 2번 표를 고친다. 지금 값은 임시.

## 1. 기본

| 항목 | 값 |

| slug (파일 이름) | `trumpet_angel` |

| 계정 / 문구 | `@justmade.lab` / 없음 |

## 5. 연출 설계

| 항목 | 이번 영상에서 | 비고 |
|---|---|---|
| 카메라 | 고정 풀샷. 이유: 기획자 요청(풀샷 고정). 스테인드글라스는 창 전체가 한 장의 그림이라 처음부터 끝까지 구도가 같아야 조각이 채워지는 과정이 읽힌다. 움직임은 음파와 깃털이 맡는다 | `camera` 쓰지 않음 |
| 층 구성 | 배경: 어둠 + 창틀·하늘 유리 / 중경: 천사 유리 / 전경: 금빛 음파, 떨어지는 깃털, 빛줄기와 먼지 | 깃털과 음파는 유리 위를 지나감 |
| 이펙트 | 금빛 음파(빛 번짐), 음파가 지날 때 납선 반짝임, 유리가 켜지는 0.4초 밝기 오버슛, 클라이맥스 뒤 역광 밝기 상승과 빛줄기, 먼지 | 섬광·흔들림 없음 |
| 색 변화 | 검정 -> 금(나팔·후광) -> 진홍·진주(천사) -> 청금석·에메랄드(배경·창틀) -> 전체 밝음 -> 검정 | 바깥으로 갈수록 차가운 색 |
| 리듬 | 음파 약 1.4초 간격으로 일정하게 반복, 10.0–11.3초 한 번 멈춰 박자를 끊고, 클라이맥스 음파는 1.2초에 걸쳐 느리게. 깃털 낙하는 음파와 엇박. 1초 이상 멈춘 화면 없음(정적 구간에도 깃털·맥동·날개) | |

## 6. HUD

1줄 `@justmade.lab`
2줄 `feathers 22   notes 11   rays 5`
3줄 `panes N`

- `notes`: 퍼진 음파 수(클라이맥스 포함 11)
- `feathers`: 떨어지기 시작한 깃털 수(22)
- `rays`: 내려온 빛줄기 수(5)
- `panes`: 켜진 유리 조각 수(0 -> 약 130)
